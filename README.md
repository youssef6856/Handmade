# Handmade — موقع أمي للهاند ميد

## التعديلات اللي اتعملت في النسخة دي

1. **أمان:** اتشال الـ `service_role` من لوحة التحكم تمامًا (كان خطر جدًا).
2. **قاعدة البيانات:** Policies للمنتجات والطلبات والـ Storage + دالة تنقيص المخزون.
3. **العملاء:** بتيجي من جدول `profiles` + طلبات الضيوف (من غير service_role).
4. **الصور:** بتضغط أوتوماتيك قبل الرفع.
5. **المخزون:** بينقص لما العميل يعمل طلب.

---

## خطوات التشغيل لأول مرة

### 1) Supabase
1. افتحي المشروع: https://supabase.com/dashboard
2. روحى **SQL Editor** → New query → الصقي محتوى ملف `database-updates.sql` كامل → **Run**
3. روحى **Storage**:
   - لو مفيش bucket اسمه `products` اعملي New bucket → الاسم: `products` → Public
   - الـ SQL فوق بيحاول يعمل الـ bucket والـ Policies تلقائي
4. **مهم جدًا للأمان:** Settings → API → اعملي **Regenerate** للـ `service_role` key (لأن المفتاح القديم كان مكشوف في الكود القديم)

### 2) غيّري باسورد الأدمن
في ملف `admin.js` غيّري السطر:
```js
const ADMIN_PASSWORD = "handmade2026";
```
لحاجة قوية تخصك بس.

### 3) تشغيل محلي
```bash
npm install
npm start
```
- الموقع: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin.html

### 4) رفع الموقع (Deploy)
أسهل طريقة:
1. ارفعي الفولدر كله على [Netlify Drop](https://app.netlify.com/drop) أو Cloudflare Pages أو Vercel
2. الدومين هيبقى جاهز في دقايق

## ملاحظات أمان

- الـ `anon` key ظاهر في الكود وده طبيعي ومصمّم لكده.
- الـ `service_role` **ممنوع** يظهر في أي ملف فرونت.
- باسورد الأدمن حالياً حماية واجهة فقط (sessionStorage). للمواقع الأكبر يُفضّل Edge Function + Supabase Auth.
- بعد تشغيل الـ SQL، أي حد يعرف رابط المشروع يقدر نظريًا يعدّل المنتجات عبر الـ API (لأن Policies الكتابة مفتوحة عشان اللوحة تشتغل من غير service_role). الحماية الأساسية = باسورد الأدمن + إن اللينك مش منشور للعامة. لو حابة أمان أقوى لاحقًا نقدر نعمل Edge Functions.

## التحديثات الجديدة (كوبونات + إعدادات)

### بعد تحميل الملفات على GitHub
1. شغّلي **database-updates.sql** كامل تاني من Supabase SQL Editor (آمن يتكرر).
2. من الأدمن هتلاقي:
   - **🎟️ كوبونات**: أنشئي كود، مبلغ أو نسبة، عدد مرات الاستخدام (1 = مرة واحدة).
   - **⚙️ إعدادات**: واتساب، شحن مجاني، أرقام الدفع، إعلان، تليجرام.
   - في المنتج: خيار **ظاهر في الموقع** لإخفاء منتج من غير حذفه.
3. عند الطلب: خانة **كود خصم** اختيارية + شريط الشحن المجاني في السلة.
4. إشعار تليجرام: حطّي Bot Token و Chat ID من الإعدادات.

### رفع على GitHub
استبدلي الملفات المعدّلة:
- admin.html, admin.js, admin.css
- index.html, script.js
